📖 О проекте

В отличие от стандартных калькуляторов с приоритетом операций (где умножение
выполняется раньше сложения), данный проект реализует логику классического
настольного калькулятора (Left-to-Right):
2 + 3 × 4 = 20 (а не 14)

Главные особенности:

- ❌ Полный отказ от eval() — все операции и цепочки рассчитываются безопасно
  через чистую математику.
- 🛡️ Строгий TypeScript — отсутствие типов any, строгие объединения (Union
  Types) для операций.
- 🧱 Архитектурный паттерн Smart/Dumb Components — разделение логики состояния
  и UI.
- 📜 История операций — хранение 5 последних успешных вычислений.

🧠 Карта состояния (State Architecture)

Управление калькулятором построено на 5 атомарных состояниях (useState) и 2
вычисляемых значениях (Derived State).

Таблица стейтов:

| Стейт           | Тип                 | Начальное | Зачем нужен и почему выбран такой тип                                                                                                                                                                                                                |
| :-------------- | :------------------ | :-------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `currentInput`  | `string`            | `"0"`     | **Сырой ввод пользователя на дисплее.** <br>• Хранится строкой, так как ввод — это конкатенация символов (`'2' + '3' = '23'`).<br>• Позволяет вводить точку (`"0."`), контролировать лимит символов (`.length <= 12`) и отображать слово `"Ошибка"`. |
| `previousValue` | `number \| null`    | `null`    | **Зафиксированное левое число для математической операции.** <br>• Хранится как `number`, так как ввод завершен и число готово к вычислениям.<br>• Защищает от багов JS-склейки строк (`5 + 3 = 8`, а не `"53"`).                                    |
| `operation`     | `Operation \| null` | `null`    | **Текущий математический знак (`+`, `-`, `×`, `÷`).** <br>• Хранит операцию, ожидающую ввода второго числа.                                                                                                                                          |
| `isNewNumber`   | `boolean`           | `false`   | **Флаг-переключатель режима ввода.** <br>• `true` — следующее нажатие цифры очистит экран и начнет новое число.<br>• `false` — следующая цифра допишется в конец текущей строки.                                                                     |
| `history`       | `string[]`          | `[]`      | **Массив строк с историей вычислений.** <br>• Ограничен последними 5 записями (`slice(0, HISTORY_LIMIT)`).                                                                                                                                           |

Вычисляемые значения (Derived State — без лишних useState):

1.  hasError (boolean): currentInput === ERROR_TEXT. Моментально блокирует ввод
    операций при ошибке.
2.  expressionText (string): вычисляется «на лету» перед рендером:
    const expressionText = previousValue !== null && operation !== null
    ? `${previousValue} ${operation}`
    : "";
    Показывает аккуратную подсказку над числом (например, 5 ×).

⚙️ Ключевые алгоритмы и переходы состояний

1. Ввод цифр (handleDigit)

- Если на экране ошибка: вызов полного сброса калькулятора и старт нового
  ввода с нажатой цифры.
- Если isNewNumber === true: экран перезаписывается нажатой цифрой, флаг
  сбрасывается в false.
- Защита от лидирующих нулей: если на экране '0', ввод другой цифры заменяет
  его, а не создает '05'.
- Лимит длины: блокировка ввода при длине >= 12 символов.

2. Ввод десятичной точки (handleDot)

- Если на экране ошибка или включен isNewNumber, точка начинает число с
  аккуратного '0.'.
- Проверка .includes('.') исключает повторный ввод второй точки (например,
  ввод 5.5.2 невозможен).

3. Операции и цепочки вычислений (handleOperation)

Функция реализует 3 сценария:

1.  Смена знака на лету: если пользователь нажал 5 +, передумал и нажал ×
    (проверяется через operation && isNewNumber), мы обновляем только знак
    операции и выходим.
2.  Подсчет цепочки (2 + 3 × ...): если есть previousValue и operation, то при
    нажатии следующего оператора сначала вызывается calculate(), результат
    выводится на экран и перезаписывается в previousValue.
3.  Первый выбор операции: текущий ввод переводится в число и сохраняется в
    previousValue.

4.  Вычисление результата (handleEquals)

- Выпрямленный код (Guard Clauses) без лишней вложенности else.
- Игнорирует незавершенный ввод вида 5 + =.
- При делении на ноль переводит калькулятор в состояние ошибки через
  resetCalculator(ERROR_TEXT).
- При успехе нормализует число через Number(currentInput) для записи в историю
  и взводит isNewNumber = true.

🛡️ Решенные краевые случаи (Edge Cases)

| Краевой случай               | Проблема                                                   | Решение в проекте                                                                                     |
| :--------------------------- | :--------------------------------------------------------- | :---------------------------------------------------------------------------------------------------- |
| **`0.1 + 0.2`**              | В JS выдает `0.30000000000000004` (IEEE 754)               | В `calculate.ts`: `Number(result.toFixed(10))` отсекает погрешность и удаляет лишние нули на конце.   |
| **Деление на ноль**          | `10 ÷ 0` возвращает `Infinity` или ломает стейт в `NaN`    | Возврат `null` из `calculate`, вывод `"Ошибка"`, полный сброс памяти оператора и операнда.            |
| **Склейка после вычисления** | Посчитали `2 + 3 = 5`, жмем `4` $\to$ экран показывал `54` | В `handleEquals` ставится `setIsNewNumber(true)`, поэтому следующая цифра стирает `5` и начинает `4`. |
| **Точка после операции**     | `5 +` затем `. 5` превращалось в `5.`                      | В `handleDot` при `isNewNumber === true` экран стартует с `"0."`, не затирая операцию сложения.       |
| **Смена знака**              | Случайное нажатие `+`, затем `×`                           | Проверка `if (operation && isNewNumber)` перезаписывает знак без выполнения вычислений.               |

🚀 Установка и запуск

1.  Клонировать репозиторий:

    git clone https://github.com/abylaikhan444/react-mini-calculator
    cd react-calculator

2.  Установить зависимости:

    npm install

3.  Запустить проект в режиме разработки:

    npm run dev

4.  Собрать проект для продакшена:

    npm run build
